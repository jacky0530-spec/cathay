🔍 客戶 JSON 備份檔驗證

此工具只在目前裝置的瀏覽器中讀取您選擇的 JSON 檔案，不傳送、不儲存、不修改客戶資料。驗證結果只顯示筆數、檔案雜湊值和異常統計，不顯示姓名、電話或備註。

⚠️ 請僅選取自己先前下載的 cathay-client-backup-*.json。勿將含個資的檔案傳到 GitHub、LINE 群組或聊天室。驗證通過也不代表已完成加密備份、雲端同步或 Firebase 權限測試。
尚未選擇檔案。

使用方式

  1. 在原本有資料的同一個瀏覽器先從 客戶資料備份工具 下載 JSON。
  2. 回到本頁選取剛剛下載的 JSON，確認「格式有效」、筆數及異常統計。
  3. 若從相同瀏覽器下載，本工具也會嘗試比對目前本機資料是否一致；若來自其他裝置，筆數不同不一定代表檔案損毀。
  4. 將檔案存入受控的加密備份空間；保留顯示的 SHA-256 校驗值，日後可再次確認檔案未改變。

本工具不會修復或還原檔案，也不會刪除瀏覽器中的 contactRecords。如顯示損毀或筆數異常，請保留原始檔案與現有瀏覽器資料，先不要進行新版系統遷移。
