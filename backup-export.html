🔐 客戶資料備份工具

提供 Cathay V1.0 安全改版前的一次性本機備份。只讀取目前這個網站、這個瀏覽器中的 contactRecords，不會刪除、覆寫、上傳或寄送任何資料。

⚠️ 本頁必須由原本存有客戶資料的同一台裝置及同一個瀏覽器開啟。請勿用無痕模式、其他瀏覽器或不同網址開啟。下載檔包含客戶姓名、電話等個資，請保存於加密空間，不要傳到公開 GitHub 或聊天群組。
正在檢查本機客戶資料…
  1. 確認上方顯示的筆數，與原本客戶管理頁的筆數相同。
  2. 點選「下載完整 JSON 備份」，將檔案存到安全的位置。
  3. 開啟下載檔，確認有 schemaVersion、exportedAt、records 三個欄位，且 records 筆數正確。
  4. 不同手機、平板、電腦的原始資料可能不同，請各自備份並保存檔案。

這是唯讀備份頁面，沒有雲端同步或其他傳輸功能。資料一直留在原瀏覽器，直到您自行清除網站資料。

下載後：檢查 JSON 備份是否完整。驗證只在本機進行，不會上傳個人資料。
